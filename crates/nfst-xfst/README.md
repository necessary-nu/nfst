# nfst-xfst

Parser, typed AST, and pretty-printer for **xfst**, the command-shell language.
Embeds [`nfst-xre`](https://github.com/necessary-nu/nfst/tree/main/crates/nfst-xre)
for inline regex bodies.

Part of the [`nfst`](https://github.com/necessary-nu/nfst) workspace, a set of
Rust parsers for the finite-state grammar languages of the HFST / Xerox
toolchain.
