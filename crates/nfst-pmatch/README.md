# nfst-pmatch

Parser, typed AST, and pretty-printer for **pmatch**, the pattern-matching
language.

Part of the [`nfst`](https://github.com/necessary-nu/nfst) workspace, a set of
Rust parsers for the finite-state grammar languages of the HFST / Xerox
toolchain.
