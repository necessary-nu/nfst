# nfst-xre

Parser, typed AST, and pretty-printer for **xre**, the Xerox
regular-expression sublanguage.

Part of the [`nfst`](https://github.com/necessary-nu/nfst) workspace, a set of
Rust parsers for the finite-state grammar languages of the HFST / Xerox
toolchain. `nfst-xre` is the base regex crate that the other grammar crates
embed for their inline regex bodies.
